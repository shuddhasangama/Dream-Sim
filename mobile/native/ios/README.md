# iOS SessionVault plugin (staging)

The `ios/` Capacitor project doesn't exist in this repo yet — it's generated by
`npx cap add ios`, which CI runs before a build. These two files aren't inside
that generated tree because it doesn't exist to hold them until that step
runs; CI copies them into `ios/App/App/` right after `cap add ios`, before
`pod install` / the Xcode build.

## Files

- `SessionVaultPlugin.swift` — the plugin implementation. A `CAPPlugin`
  subclass backed by the iOS Keychain (`kSecClassGenericPassword`,
  `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly` — not backed up, not
  synced to other devices).
- `SessionVaultPlugin.m` — Objective-C registration (`CAP_PLUGIN`). Capacitor
  discovers native plugins through this file, not the Swift class alone.

## Contract

Mirrors `android/app/src/main/java/com/dhashu/app/SessionVault.java` exactly
in observable behaviour — this is what `src/main.js`'s `vault` wrapper and
`Session` rely on, regardless of platform:

| Method  | Call                    | Resolves                          | Rejects with                                      |
|---------|-------------------------|------------------------------------|----------------------------------------------------|
| `write` | `{ value: string }`     | *(nothing)*                        | `"Invalid credential."` if `value` isn't 32-128 chars; `"Secure storage unavailable."` on any storage failure |
| `read`  | *(nothing)*             | `{ value: string \| null }` — `null` if nothing stored | `"Stored session is unavailable. Sign in again."` if the stored entry can't be read back (also clears it, same self-heal as the Android side) |
| `clear` | *(nothing)*             | *(nothing)*                        | `"Could not clear secure storage."` if the delete itself fails |

Plugin name is `"SessionVault"` (must match `registerPlugin('SessionVault')`
in `src/main.js` and the Android side's `@CapacitorPlugin(name = "SessionVault")`).

## Copying into the generated project

Once `ios/App/App/` exists:

```bash
npx cap add ios
cp mobile/native/ios/SessionVaultPlugin.swift ios/App/App/
cp mobile/native/ios/SessionVaultPlugin.m ios/App/App/
npx cap sync ios
```
